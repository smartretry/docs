---
title: Charge recurring
description: Manually trigger a charge against an active merchant-managed recurring series.
openapi: "/api-reference/openapi.json POST /v1/payments/recurring/charge/{terminal_friendly_id}"
---

Submit a charge against an existing recurring series by its `recurring_id`.

<Note>
  Safe retries for this POST endpoint use the `Idempotency-Key` header. Reuse the same key only when retrying the exact same request body. See [Idempotency](/api-reference/idempotency).
</Note>
